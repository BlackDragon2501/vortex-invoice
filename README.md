# Vórtex Invoice

Vórtex Invoice, de Vortex Company: crea facturas para freelancers con emisor, cliente, conceptos ilimitados, impuestos porcentuales, 9 monedas y notas; descarga el PDF (jsPDF dentro del navegador) y lleva un historial vivo en IndexedDB con edición y duplicado. Nada se sube a ningún servidor. Gratis, sin anuncios y 100% local.

## Stack

- Next.js 16 + React 19 + Tailwind 4 + TypeScript
- jsPDF para generar el PDF en el cliente
- IndexedDB para el historial local
- 100% local en el navegador, sin backend y sin variables de entorno

## Desarrollo

```bash
bun install
bun run dev
```

## Producción

```bash
bun run build
```
